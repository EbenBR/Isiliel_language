3. Methodology

  • Command: make bench — compiles bench/host_bench.cpp with -O2 -DNDEBUG -flto, runs the 5 benchmarks in both interpreters, and validates the checksums.
  • Measured time: load + execution (source compilation included on both sides); best of 3 runs.
  • Versions: Lua 5.4.6 (liblua5.4.a from the Ubuntu package, built with -O2) vs Isiliel 1.0 (-O2 -DNDEBUG).
  • Environment: Ubuntu (g++ 13.3.0), Intel Core i7-11800H @ 2.30GHz, x86_64.
  • Correctness: each benchmark produces a numeric checksum identical on both sides (2997000000, 196418, 300000, 125000250000, 807857) — a mismatch fails the host.
  • Complex numbers: Mandelbrot z = z² + c at 200×200 with 50 iterations; Isiliel uses the native complex type and Lua uses two scalars (there is no native complex type).
  • Sources: bench/lua/*.lua, bench/isl/*.isi, host in bench/host_bench.cpp.
